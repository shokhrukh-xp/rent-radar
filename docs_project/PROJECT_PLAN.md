## 0. Суть проекта в трёх строках

Ra'no — ИИ-ассистент по подбору жилья: анкета → письмо маклерам → приём вариантов в бота
→ триаж «да/нет» → переписка от имени клиента → шортлист → сделка. Монетизация: первые
проверенные варианты бесплатно, остальные после оплаты. Ценовой индекс — только по данным
маклеров. Ra'no всегда ИИ, имя клиента маклерам не раскрывает, спам-рассылок нет.

## 3. Принципы и ограничения (не нарушать)

- Ra'no всегда представляется ИИ-ассистентом. Имя клиента маклерам не раскрывается.
- Никакой автоматической массовой рассылки с личных аккаунтов; маклеры пишут боту первыми.
- Секреты только в GitHub Secrets / env, никогда в коде. Репо публичный → в `docs/` без PII;
  базы с данными — только в приватном `rent-radar-state`, в публичный репо не коммитить (`.gitignore`).
- Тексты клиенту — тёплые, честные, без тёмных паттернов (счётчики реальные).
- Ценовой индекс — только по данным маклеров, не по листингам порталов.
- Правильное имя: **Ra'no** (Raʼno / Раъно) — везде латиницей с апострофом.
